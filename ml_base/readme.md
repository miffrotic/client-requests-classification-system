# Итог чекпоинта

В результате работы:
- **Воспользовались четырьмя методами векторизации данных**
    - Bag Of Words
    - TF-IDF
    - Word2Vec
    - FastText

Каждый векторайзер был обучен на тренировочном датасете и сохранён для дальнейшего применения в моделях классификации (в частности, для будущего обучения нелинейных моделей). 

- **Выбрали основную метрику качества**

Сравниваем качество модели при помощи основной метрики - **Weighted F1**. Она балансирует важность классов при дисбалансе данных, учитывает и точность, и полноту  

Также наблюдаем за micro/macro F1, precision и recall отдельных классов. 

- **Обучили несколько линейных моделей**
    - Логистическая регрессия
    - Метод опорных векторов (LinearSVC)
    - Наивный Байессовский классификатор (GaussianNB)
    
Модели обучались на данных, преобразованных каждым из четырёх векторайзерах, с небольшим подбором гиперпараметров при помощи **GridSearchCV**.

> В результате, лучшим решением оказалось сочетание **BoW+LinearSVC** со стандартными гиперпараметрами. Получившееся значение **Weighted F1=0.9627** на валидационной выборке. Модель сохранена для дальнейшего использования в проекте

Из интересных наблюдений - чем более "продвинутый" алгоритм векторизации данных, тем хуже Logreg и SVC показывали себя. Скорее всего, линейные модели слишком простые для получения хорошего качества на более сложных алгоритмах векторизации. Следует сравнить результаты с деревьями, бустингами и нейросетевыми моделями.
